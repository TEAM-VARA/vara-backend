1. 평가 목적
================================================================================

본 보고서는 조직의 중대한 환경 변경 발생 시 위험 재평가 결과를 기술한다.
아키텍처 변경, 신규 서비스 도입, 법규 변경 등 재평가 트리거가 발생할 경우
30일 이내(재평가 시한)에 위험 재평가를 수행하도록 규정하고 있다.

재평가 트리거 기준:
 - 아키텍처 변경: 인프라 구조 변경, 신규 클라우드 서비스 도입
 - 서비스 변경: 신규 서비스 런칭, 주요 기능 변경
 - 법규 변경: 정보보호 관련 법령 개정, 인증 기준 변경

3. 재평가 결과
================================================================================

[변경 1] EKS 클러스터 v1.28 → v1.30 업그레이드
  재평가 일자: 2025-02-25 (변경 후 10일 이내)
  영향 범위: 컨테이너 런타임, 네트워크 정책, Pod Security Standard
  결과: 위험 수준 변동 없음
   - 신규 보안 기능 (Pod Security Admission) 적용으로 보안 수준 향상
   - 기존 네트워크 정책 호환성 확인 완료
   - 추가 조치 사항: 없음

[변경 2] 신규 모바일 결제 서비스 런칭
  재평가 일자: 2025-03-20 (변경 후 19일 이내)
  영향 범위: 결제 API, PG 연동, 개인정보 처리 흐름
  결과: 신규 위험 2건 식별
   - RISK-NEW-001: 결제 API에 대한 부정 거래 위험 (High)
     → 보호대책: 이상거래 탐지 시스템(FDS) 적용 (2025-04-15까지)
   - RISK-NEW-002: 결제 정보 전송 구간 암호화 미흡 (Medium)
     → 보호대책: TLS 1.3 강제 적용 확인 (즉시 조치 완료)

[변경 3] 개인정보보호법 시행령 개정
  재평가 일자: 2025-03-25 (변경 후 24일 이내)
  영향 범위: 개인정보 수집·이용 동의 절차, 파기 절차, 보관 기간
  결과: 위험 수준 상향 1건
   - RISK-2025-008 (법규 위반 위험): Medium → High로 상향 조정
     → 보호대책: 동의서 양식 개정, 개인정보 파기 절차 자동화 (2025-04-30까지)
